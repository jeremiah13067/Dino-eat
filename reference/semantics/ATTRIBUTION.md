The unmodified JavaScript files in this directory are read-only research
references downloaded from scratchfoundation/scratch-editor, develop branch,
during this conversion. They are not imported or executed by the Python game.

Source: https://github.com/scratchfoundation/scratch-editor

Package sources: packages/scratch-vm and packages/scratch-render. Their upstream

is included as LICENSE-Scratch-AGPL-3.0.txt. Original notices remain in the files.

The optional reference harness installs the separately licensed upstream npm
packages for local verification; their implementations are not bundled into
this Python application's runtime or ZIP.
